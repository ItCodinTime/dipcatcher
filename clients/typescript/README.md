# dipcatcher research API — TypeScript client

Typed, zero-runtime-dependency client for the read-only research evidence API
(`quant_fund.api.research_api`). It lists and fetches research run notebooks,
committed receipts, sealed benchmark results, and verifier acceptance history.
The service it talks to is **read-only** — it has no trading, order, broker, or
execution endpoints.

## Contents

- `openapi.json` — committed OpenAPI 3.1 snapshot of the service.
- `schema.d.ts` — generated by `openapi-typescript` from `openapi.json`.
- `client.ts` — hand-written thin `fetch` wrapper whose method return types are
  bound to `schema.d.ts` (`GetJson<"/path">`), so it cannot drift from the spec.

## Regenerate

```bash
# from the repo root — re-exports the spec from the live FastAPI app
uv run --no-sync python scripts/export_research_api_openapi.py

# from clients/typescript — regenerates schema.d.ts
npx --yes openapi-typescript openapi.json -o schema.d.ts
```

## Typecheck

```bash
cd clients/typescript
npx --yes -p typescript@5.6.3 tsc --noEmit --strict --module nodenext \
  --moduleResolution nodenext --target es2022 --skipLibCheck \
  --allowImportingTsExtensions client.ts
```

## Usage

```ts
import { ResearchApiClient } from "./client.ts";

const api = new ResearchApiClient(); // http://127.0.0.1:8010
// const api = new ResearchApiClient({ apiKey: process.env.RESEARCH_API_KEY });

const runs = await api.listRuns({ limit: 25 });
for (const run of runs.items) {
  const verdict = await api.verifyRun(run.run_id);
  console.log(run.run_id.slice(0, 12), verdict.valid, verdict.errors);
}

const receipt = await api.getReceipt("incumbent_bench_qlib");
console.log(receipt.schema_tag, receipt.sha256);
```

Start the server locally:

```bash
uv run --no-sync uvicorn quant_fund.api.research_api:app --host 127.0.0.1 --port 8010
```

## Auth note

The service binds `127.0.0.1` and serves only loopback clients unless
`RESEARCH_API_KEY` is set on the server, in which case every non-`/health`
route requires `X-API-Key` (pass it via `apiKey`). It holds no credentials and
exposes no trading surface, but never expose it on a non-loopback interface
without a key anyway.
