# quant_fund.data

Point-in-time lake I/O, ingest, and opt-in public-source collection. Collection may use the network. Bar ingest of local artifacts stays offline. Nothing in this package submits orders.

`hf_ohlcv_1m` maps the Hugging Face minute-bar dataset onto the bronze bar contract. Adjustment is undeclared. The narrative spec is [HF OHLCV-1m](../HF_OHLCV_1M.md).
