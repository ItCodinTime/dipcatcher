# quant_fund.metrics

Proper scores and probability diagnostics used as research headlines: pinball, CRPS, QLIKE, log score, Brier, ECE, Kupiec, Christoffersen tests, PIT, and e-processes.

The formulas are in the [mathematical specification](../MATH_SPEC.md). The package module `quant_fund.metrics` re-exports these callables.
