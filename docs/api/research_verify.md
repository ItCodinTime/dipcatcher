# quant_fund.research.verify

Fail-closed checks on a persisted research receipt. `verify_research_artifact` validates identity, seals, and honesty flags. A valid receipt is evidence that the notebook matches its seals. It does not interpret scores as a live result.

The operator workflow is [Receipt verification](../RECEIPT_VERIFICATION.md). The CLI is `dipcatcher verify-research`.
